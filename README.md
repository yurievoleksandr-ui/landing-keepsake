# Landing Keepsake — Digital & Branding Agency

Лабораторна робота №7 (Завдання 4–5).
Адаптивна верстка лендінгу за макетом у Figma без використання сторонніх CSS/JS фреймворків.

## Використані технології
* **HTML5** (семантична розмітка)
* **CSS3** (Flexbox, CSS Grid, CSS-змінні `:root`, медіазапити)
* **Підхід:** Mobile First (375px -> 768px -> 1280px)
